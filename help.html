電卓を開く

プログラム関数電卓の使い方

配置と結果の共有

  • SHIFT → MODE（SETUP）または MODE → SETUP から「配置」を開くと、縦横・表示・ボタンの並びや、カーソルキーの位置と大きさを変えられます。標準の縦型では、液晶下端のつまみを動かすと高さが変わります。
  • 「名前を付けて保存」で配置と表示設定をまとめて覚えます。「呼び出す」で保存した向きへ切り替え、設定を反映します。同名で保存するときは上書きを確認します。
  • 自由配置で窓を動かすと、隣に当たった縁で止まります。縁に沿ってずらすこともできます。右下でサイズを変えるときは、近くの窓の縁に吸着します。キーのある窓は、表示が読める最小の大きさまで縮められます。
  • 計算後やプログラムが答えを表示しているときは、液晶の下の「結果」からテキストをコピーできます。端末が対応していれば「共有」も使えます。
  • 座標を聞かれたときは液晶内の「座標一覧から」で点を選べます。Y の行に点名が出ます。同じ座標が後から機械点などに移っても点名を表示します。

キーの基本

  • SHIFT の後にキーを押すと、キーの左上（黄色）の機能。ALPHA の後は右上（赤）の文字。SHIFT→ALPHA で文字を続けて入れる A-LOCK。
  • 液晶の上の D（角度）や Norm・Fix（表示の桁）をタップすると、その場で切り替えられます。
  • 閉じカッコは式の最後なら省略できます（(2+3)(4-1 → 15）。
  • 乗算記号は省略できます（2A、3(4+1)、2sin(30)）。
  • ▲▼ で前の計算式を呼び出し（REPLAY）、◀▶ で直前の式を直せます。
  • PC ではキーボードの数字・記号・Enter・BackSpace・Esc・矢印も使えます。Shift だけを押して離すと電卓の SHIFT と同じです。
  • SHIFT・ALPHA が有効な間は、キーの表記がその機能（黄色・赤）に変わります。薄いキーはその機能がありません。

度分秒

  • °′″ キーを度・分・秒の後に押します：2°30°30° ＝ 2°30′30″。
  • 答えの表示中に °′″ を押すと 60進数 ⇔ 10進数 を切り替え。SHIFT °′″ は ▸DMS（答えを度分秒で）。
  • 角度を聞くプログラムでは前回の値を 000-00-00 形式で表示します。060 と打つと分へ、00 と打つと秒へ移ります。左右キーや欄のタップでも移れます。EXE で確定します。新しく入力を始めた場合、空いた欄は 0 になります。

メモリー

  • SHIFT RCL（STO）→ 文字キー：式（答え）を変数 A〜Z に記憶。
  • RCL → 文字キー：変数の値を呼び出し。文字キーは ALPHA なしで押せます。
  • M+／SHIFT M+（M−）：独立メモリー M に足す・引く。
  • MODE → VAR で A〜Z の一覧。SETUP → ClrMemory で全部0。

CALC・SOLVE・FMLA

  • CALC：変数を含む式（例 3×A+B、S=A×B÷2、"MENSEKI":S=A×B÷2）を入れて CALC。変数の値を入れて EXE。もう一度 CALC で値を変えて再計算。
  • SOLVE：方程式（例 Y=AX²+B）を入れて SOLVE。値と初期値を入れ、▲▼で解く変数を反転させて SOLVE。
  • FMLA：内蔵公式（測量の座標計算・逆計算・単曲線・ヘロン など）と自作公式（Formula モードのプログラム）。値を順に入れて EXE。答えが複数なら EXE で次へ。

プログラム

PC でプログラムを書くときは プログラム エディター が便利です（入力候補・記号のショートカット・文法チェック・.ccl/.cce の読込）。同じブラウザなら電卓と中身が共通です。

  • PC・タブレットでは、PROG の NEW・EDIT で PC 用エディターが開きます（スマホは電卓の画面で編集）。
  • FILE キーでプログラム一覧（実行）。MODE → PROG で NEW（新規）・EDIT（編集）・DELETE・txt 読込／書出・バックアップ。
  • 編集中：電卓のキーで入力、EXE で改行、SHIFT EXE で ◢、EXIT で保存して戻る。「キーボードで編集」でスマホのキーボードを使えます。
  • FUNCTION → PROG で命令の一覧（If・For・While・Lbl・Goto・Locate・Getkey など）。SHIFT ×＝?、SHIFT ÷＝:、SHIFT S⇔D＝→、ALPHA M+＝"。
  • 実行中：◢ で止まったら EXE で続き。AC で中断。終わったら EXE でもう一度。
  • txt の読み書きは CcEditor の書式（UTF-8・→ ◢ ⇒ ≠ ≦ ≧ ▸DMS Z[n]）に合わせています。
  • IMPORT では、電卓から CcLinker で吸い出した .ccl と、CcEditor の .cce もそのまま読めます（複数まとめて選べます。同じ名前は新しい方を使います）。スマホでは Dropbox などのファイルから選べます。
